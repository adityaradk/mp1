## What is this website?

This is a website for Bob's 10-in-1. It is a shampoo, conditioner, moisturizer, sunscreen, toothpaste, mouthwash, shaving cream, skin toner, foot cream, and mayonnaise.

## How is this website structured?

We have several sections. While the boilerplate for this is already available in the HTML, this is how it is to be structured:
1. Main: this is going to use the static image background. The foreground is centered bold text that says "Bob's 10-in-1" with a smaller header beneath it "Your one-stop-shop for all things personal hygine".
2. Functionality: this is supposed to have 10 small modal windows. Each has a small title for each of the functionalities and below that a small context text like "Clean hair" for shampoo. Then when you click, you get the expanded version of the modal and yeah you get a paragraph of detail about each of the functionalities.
3. About: this is supposed to have three columns. Each column will have three icons (meeting the icon requirement) with the icons and header center aligned. The columns are:
    - "Who are we" -- Bob's 10-in-1 is a family-run business for 15 generations. We noticed how people were buying 10 products for 10 things and decided to make it one product that does everything.
    - "Where are we" -- Bob's 10-in-1 is in every store in America, except in Kansas and at some Chipotle locations.
    - "The future" -- Bob's son, Bob is proud to carry on the family legacy. Our new products include an 11-in-one which will soon be usable as engine oil.
    - The icons for the above are a user icon, a map icon, and a question mark icon.
4. Money back guarantee: this is a brief second static image background thing where we have foreground text that moves while the image stays static. This text reads: "SATISFACTION OR YOUR MONEY BACK (100% return fee applies)".
5. Reviews: this is supposed to be the carousel. Make three reviews from three people and two navigators on either side that you flank.
6. Support: Let the video fill the full background and loop automatically thanking the users for getting our product.
7. Contact: This is a footer that meets the assignemnt requirements, has social media icons that just direct to the website (e.g., Twitter -> twitter.com) in other words no need to actually direct to a real social media webpage, just the websites for now as placeholders. Add a Copyleft.

There is also a navbar that needs to meet some requirements. Make sure the color scheme is tasteful and aligns with the background image in background.png that I've chosen. In general, make sure there's good readability and aesthetics all around.

Make sure to also do the following:
- Bar and font must shrink as you scroll down
- Position indicator on Nav -- Highlight current section; must highlight the last item at page bottom
- Add a fade in animation when you scroll to about.
- The website MUST be responsive. You can see the test cases in the assignment README, but yeah. Has to be something that is good.

Some advice on code: do not implement any functionality that is strictly not necessary, make sure things are tasteful and clean, write code with good comments -- do not explain your thought processes or leave notes in your code, rather write code that allows a human to understand your work and make changes to make things better.
